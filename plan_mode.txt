プランモード（Plan Mode）について
====================================

1. プランモードとは
   Claude Code で、コードやファイルを変更する前に「調査と計画」だけを行うモードです。
   いきなり作業を始めるのではなく、まず何をどう進めるかをまとめて、ユーザーの確認を取ります。

2. 特徴
   - 使えるのは読み取り専用の操作（ファイルの閲覧・検索など）だけです。
   - ファイルの編集、コマンドの実行、git コミットなどは行いません。
   - 例外として、計画を書き込む「プランファイル」だけは編集できます。

3. 作業の流れ
   (1) 調査   : 関連するファイルやコードを読んで現状を把握する
   (2) 設計   : どのように変更するかを考える
   (3) 質問   : 不明点があればユーザーに確認する
   (4) 提示   : 計画（プラン）をユーザーに見せる
   (5) 実行   : ユーザーが承認したら、プランモードを抜けて実際の作業を行う

4. 切り替え方法
   Shift+Tab を押すとモードが切り替わります。
   （通常モード → 編集の自動承認モード → プランモード の順に切り替わります）

5. メリット
   - 大きな変更の前に方針を確認できる
   - 意図しない変更やファイルの破損を防げる
   - 作業内容が事前に分かるので安心して任せられる

6. 今回の実験について
   このファイル自体が、プランモードで計画を立て、
   ユーザーの承認を得てから作成されたものです。
